# VeroRun Education Edition

**VeroRun 教育版（科研知识库）** —— 激活后解锁 7 个内置插件。

本仓库为教育版落地页，由 `sync-to-edu` CI 流水线维护，**仅包含本说明文档**（不含任何代码）。教育版内核从 `verorun-standard` 获取，插件通过内置插件商店安装。请勿手动推送本仓库。

---

## English

## Overview

The Education Edition targets research & knowledge-base scenarios. Activating the Edu edition unlocks 7 bundled plugin entitlements, installed on demand from the built-in plugin store — **no plugin is bundled in any distribution**.

Bundled plugin entitlements (Edu):

- `project_workspace` — isolated project workspaces
- `health_check` — service health inspection
- `memory_engine` — Agent memory
- `vault` — backup & audit
- `content_factory` — content ingestion
- `email` — email delivery
- `veroscholar` — research literature

## Getting Started

1. Deploy the core from `verorun-standard`.
2. Activate the Edu edition in the admin console.
3. Install the unlocked plugins from **Admin → Plugins → Store**.

## 中文

## 概述

教育版面向科研与知识库场景。激活教育版后解锁 7 个内置插件授权，插件通过内置插件商店按需安装（**任何发行版均不捆绑插件**）。

教育版内置插件授权清单：

- `project_workspace`（项目隔离）、`health_check`（健康检查）、`memory_engine`（Agent 记忆）
- `vault`（备份审计）、`content_factory`（内容采集）、`email`（邮件）、`veroscholar`（科研文献）

## 快速开始

1. 从 `verorun-standard` 部署内核。
2. 在管理后台激活教育版。
3. 在 **管理后台 → 插件 → 商店** 安装已解锁的插件。
